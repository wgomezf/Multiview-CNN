<ul><li>The MV-CNN.zip file contains the functions to build a multi-view convolutional neural network for classifying breast tumors into benign and malignant classes. Two kinds of fusion blocks can be set: Serial and ResNet.</li></ul>

<ul><li>The ReconfigMultiCNN.zip file contains the functions to build a reconfigurable multi-view convolutional neural network for classifying breast tumors into benign and malignant classes. The fusion blocks are switchable and can be activated or deactivated using a binary string.</li></ul>

Before running these demos, download and install the ResNet18 network (https://www.mathworks.com/matlabcentral/fileexchange/68261-deep-learning-toolbox-model-for-resnet-18-network). All the functions were developed and tested in MATLAB 2024b.
